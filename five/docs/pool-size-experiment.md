# 池子大小實驗（2026-10-10）

## 問題

現行規則是抽到什麼就下什麼（池子 N = 1）。如果改成「從袋子抽 N 顆放進池子，輪到的人從池子挑一顆下，拿掉的再從袋子補一顆」，N 從 1 到 8 時，對局會怎麼變？特別是：N 等於多少時，用五連獲勝的比例最高？

## 結論

1. **五連結束的比例隨 N 上升，到 N = 7～8 最高，N = 6 之後幾乎不再增加。** 以 v8 4 層自我對戰為例：N = 1 是 25%，N = 7 是 50%，N = 8 是 49%，後兩者在誤差內打平。其他棋力也一樣，初學者 N = 8 是 61%，6 層 v8 在 N = 5～8 都在 61～63% 之間。
2. **N 決定這個遊戲是黑白棋還是五子棋。** 強的棋手在 N = 1 時很會擋，只有 24% 的局由五連結束（初學者是 44%）。N 一變大就擋不住了，6 層 v8 在 N = 3 已經過半，N = 8 時 63%，反而比初學者還高。
3. **想讓兩種勝法各佔一半，強棋手約 N = 3，中等棋手約 N = 6～7。**
4. **N 越大，對局越短、五連越早出現。** 6 層 v8 的平均手數從 54 手降到 37 手，五連平均在第 24 手出現，四分之三的五連在第 30 手之前完成，比較像速戰速決的五子棋。
5. **實力差不太受 N 影響。** 4 層對 2 層在每個 N 下都贏 92～95%，池子大小沒有明顯放大或縮小實力差（這組實力差太大，可能碰到天花板，見下方注意事項）。
6. **N 變大時，白方的優勢會稍微縮小。** 4 層自我對戰中，白方勝率從 N = 1 的 64% 降到 N ≥ 4 的 58% 左右。不過這個白方優勢有一部分是淺層搜尋的奇偶效應（6 層幾乎沒有，初學者完全沒有），所以只能說明趨勢。
7. **各自一手（private）與共用池子（shared）的五連比例差不多。** 各自一手在 N 小時略低，到 N = 8 仍在上升（58%）。
8. **N = 8 時 CPU 每一步要算 8 次**（每顆候選棋各搜尋一次），思考時間大約是 N = 1 的 6～7 倍。

## 方法

- **對局程式：** `five/tests/pool-size.js`。直接用規則函式模擬，不經過遊戲引擎。
- **開局與補棋：** 開局四顆照常隨機抽，接著抽 N 顆進池子。每一手從池子挑一顆，下完立刻從袋子補一顆，袋子空了就不補。
- **勝負判定：** 和遊戲相同。連成五立刻獲勝，否則比棋子數。
- **黑白：** 兩邊輪流執黑，同一組設定內用固定種子，可以重現。
- **棋手：**
  - **初學者（novice）：** 池子裡任何一顆棋放在任何位置能連成五就下，否則棋和位置都隨機。
  - **v8 d 層：** 池子裡每一顆棋都用 v8 搜尋 d 層，挑分數最高的「棋＋位置」。終盤剩 5 格以內精確計算。
- **五組實驗：**

| 代號 | 內容 | 每個 N 的局數 |
| --- | --- | --- |
| novice | 初學者自我對戰，共用池子 | 4000 |
| main | v8 4 層自我對戰，共用池子 | 400 |
| strong | v8 6 層自我對戰，共用池子 | 120 |
| gap | v8 4 層（A）對 v8 2 層，共用池子 | 300 |
| private | v8 4 層自我對戰，各自一手 N 顆 | 300 |

總共約 4 萬局，8 核心跑了 69 分鐘。原始資料在 `five/tests/results/pool-2026-10-10.jsonl`。

## 注意事項

- **v8 不懂池子。** 它的搜尋假設未來的棋是隨機抽的（N = 1 的世界），沒有模擬「對手會從池子挑最需要的那顆」。第二輪讓搜尋懂池子後重測，共用池子的數字只差幾個百分點（見下方）。
- **淺層搜尋偏向白方。** 1～2 層 v8 自我對戰時白方會贏八到九成（直接用遊戲引擎也一樣），4 層仍偏白，6 層才接近平衡。所以實驗不用 1～2 層自我對戰，黑白勝率的數字也只看趨勢。
- **6 層每個 N 只有 120 局，**誤差約 ±9%，N = 5～8 之間的差異不顯著。
- **實力差那組可能碰到天花板。** 4 層對 2 層差太多，每個 N 都贏九成以上。要看池子是否放大實力差，應該用更接近的兩個棋力（例如相鄰難度）再做一次。

## 第二輪：讓搜尋懂池子（N = 3～6）

第一輪的 v8 不懂池子：它假設之後每一手都是隨機抽一顆，不知道對手能從池子挑。第二輪讓搜尋懂池子再重測一次，只測 N = 3～6，種子和第一輪相同（開局一樣，可以直接對照）。

### 懂池子的搜尋怎麼做

在 `src/ai/v8/search.js`，加上 `pool` 參數時啟用：

- **對手的下一手：** 對手看得到池子裡剩下的棋（共用池子是我挑剩的 N − 1 顆加一顆補進來的隨機棋，各自一手是對手手上的 N 顆）。只要其中有一顆能讓對手連成五，搜尋就當成對手一定連成五，不再打折。
- **終盤精確計算：** 剩 5 格以內照池子規則逐一展開，包括下棋者挑哪一顆棋、下在哪裡，以及補進來的是哪一顆。
- **更深的幾手：** 試了兩種做法。第一種是「每一手都從 N 顆隨機棋裡挑」（`deep: true`），第二種是「仍當成隨機抽一顆」（`deep: false`）。

N = 1、池子沒有別的棋時，懂池子的搜尋與原本的結果完全相同（`tests/five.test.js` 驗證）。

### 懂池子有沒有比較強？

懂池子的 v8 4 層對不懂池子的 v8 4 層，共用池子：

| 版本 | N = 4 | N = 6 |
| --- | --- | --- |
| 第一版（把盤上以平均棋代入的棋也當成挑過的，高估連五） | 41%（300 局） | 46%（300 局） |
| `deep: true`（修正後） | 45%（200 局） | 51%（200 局） |
| `deep: false` | 52%（200 局） | 52%（200 局） |

200 局的誤差約 ±7%（95%），兩個修正後的版本都跟不懂池子的版本打平。原因是原本的 v8 在當下這一手已經會試池子裡每一顆棋，池子最主要的好處早就拿到了；懂池子只影響更深幾手的估計，在 4 層搜尋裡差別不大。重測用 `deep: false`（至少不比較弱）。

### 第二輪的結論

1. **在 N = 3～6 之間，N = 6 的五連比例最高**（4 層 45%、各自一手 59%）。6 層在 N = 5 是 58%、N = 6 是 55%，誤差內打平，N = 5 之後就不再增加。整體趨勢和第一輪一樣：N 越大，五連越多。
2. **懂池子的強棋手稍微更會擋。** 共用池子時，五連比例在每個 N 都比第一輪低一點：4 層低 1～4 個百分點（單格不顯著），6 層低 4～6 個百分點（四格合計約 480 局，58.5% → 53.5%，接近顯著）。6 層的對局也變長，平均多 2～5 手，五連平均晚 3～6 手出現。
3. **各自一手時反而更常連成五。** 每個 N 都比第一輪高 6～9 個百分點（四格合計 1200 局，43.7% → 51.2%，明顯）。各自一手時，懂池子的搜尋知道對手手上確切有哪些棋，能判斷對手下一手到底擋不擋得住、能不能反過來連五，所以敢放心地排長線。
4. **第一輪的「v8 不懂池子」偏差不大。** 共用池子的數字只差幾個百分點，第一輪的結論不變。
5. **白方優勢仍在。** 4 層自我對戰白方勝率仍有 58～65%，這是淺層搜尋的奇偶效應，6 層幾乎沒有。
