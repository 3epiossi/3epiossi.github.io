
# 🎲 誰會贏？ (Who will win?)

> 🎮 **線上直接遊玩**：[https://3epiossi.github.io/](https://3epiossi.github.io/)  
> 🖥️ **本地對弈**：在專案資料夾執行 `npm start`，再用瀏覽器開啟 `http://localhost:8000`（程式以 ES 模組載入，直接雙擊 `index.html` 在多數瀏覽器會被擋下）

本專案是無外部依賴、不需建置的純前端網頁對弈系統。支援任意組合的人類／CPU 對戰（含人類 vs 人類、CPU vs CPU 觀戰）、自由排盤、對局歷程時光機與分支、**v1 至 v5** 五階演算法 CPU 與 AI 教練提示，並內建圍棋式「割目（貼目）」平衡機制，介面提供中文、English、日本語。

### ✨ 功能一覽
* **對弈設定**：每方可選「我」或 CPU，並各自挑選演算法強度；可調 CPU 行棋速度與割目（0 ~ 9.5 目）。
* **AI 教練**：一鍵列出前三名候選走法與優缺點說明，可預覽路徑，或直接點棋盤上的候選目的地採用。
* **主題與外觀**：棋盤主題、黑白棋子外觀（寶石預設、自訂色彩、上傳圖片、3D 高光開關）、移動路徑樣式（步數指示／毛筆筆觸）與顏色、遊戲音效、雙方自訂名稱。
* **左右互換**：把黑棋放在左上、白棋放在右下，座標與比分一併對調（僅畫面翻轉，不影響規則）。
* **終局表現**：結束時直接在比分板上以光效、彩帶與音效顯示勝方。
* **規則學院**：`tutorial.html` 內含互動式規則教學與題目。

## 📜 遊戲規則說明書

### 📌 用具與初始配置
1. **棋盤與棋子**：標準 $8 \times 8$ 棋盤（座標橫列 A～H、縱行 1～8），黑白雙色棋子。
2. **骰子**：標準六面點數骰子（每回合擲 1 顆骰子，點數即為該步可走步數）。
3. **初始盤面**：
   - ⚪ **白棋**：開局置於左上角 **A1** 格。
   - ⚫ **黑棋**：開局置於右下角 **H8** 格。
4. **先後手**：**黑棋先動**，黑白雙方依序輪流行棋。

---

### ⚖️ 割目（貼目 / Komi）平衡機制
實戰測試表明，若每回合走兩顆骰子（Connect6 模式），白棋後手反獲顯著連動優勢；而回歸每回合 1 顆骰子，遊戲節奏最為簡潔純粹、易於理解。<br>
為平衡一顆骰子下黑棋的先手推進優勢，比照圍棋國際標準引入**「割目（貼目）」平衡機制**：
* **白棋割目補償**：終局計算雙方在盤面上的勢力子數時，白棋額外獲得割目補償子數（預設 **+3.5 目 / 子**，亦可在「⚙️ 設定」中選擇 0 ~ 9.5 目）。
* **勝負裁定**：白棋最終得分為 $\text{盤上白子數} + \text{割目}$。若黑子數 > 白棋最終得分，則黑棋勝；若白棋最終得分 > 黑子數，則白棋勝。
* **半目杜絕和局**：採用帶有 0.5 目的設定（如 3.5 目），可客觀杜絕平手局面，精準裁定勝負。

### 📖 五大核心規則

#### 【規則一 —— 範圍與方向】
* 每回合擲出 1 顆骰子，點數即為該步棋的行棋**步數 $D$**。
* 在無敵方阻礙的前提下：
  - ⚫ **黑棋**：每一步可自由選擇「**向左 $\leftarrow$**」或「**向上 $\uparrow$**」（朝左上方進攻），直到走滿 $D$ 步。
  - ⚪ **白棋**：每一步可自由選擇「**向右 $\rightarrow$**」或「**向下 $\downarrow$**」（朝右下方進攻），直到走滿 $D$ 步。

#### 【規則二 —— 生子（增殖繁衍）】
* 玩家可任選一顆**己方棋子**作為起點。
* 依照規則一的行進方向（可於中途自由轉向折線），在走滿 $D$ 步所抵達的目標空格上，**生出一顆全新的己方棋子**。
* 起點的原始棋子依然保留於盤上，盤面己方棋子數增加一顆。

#### 【規則三 —— 吃子（純直線突擊）】
* 若要吃掉對方的棋子，其行進範圍與規則一不同：**只能一直純直線直行**骰子的步數 $D$（不可中途轉彎，如同象棋的「車」一樣直線衝鋒）：
  - ⚫ **黑棋**：只能一直純向左走 $D$ 步、或一直純向上走 $D$ 步。
  - ⚪ **白棋**：只能一直純向右走 $D$ 步、或一直純向下走 $D$ 步。
* 目標格必須恰好是**敵方棋子**。
* 吃子採「**移動方式**」：起點棋子直接移動到目標格並移除敵棋（原起點格變空，不可生子）。

#### 【規則四 —— 通過（友軍無阻）】
* 在行進路徑的途中，若遇到**己方棋子**，己方棋子**不會阻擋路徑**（生子折線路徑或直線吃子路徑均可直接穿透過去）。
* **注意**：最終落子的目標格**不能**是已有己方棋子的格子（同一格內不可疊放兩顆己方棋子）。

#### 【規則五 —— 阻擋（敵軍壁壘）】
* 在行進路徑的途中，若遇到**敵方棋子**，該條路徑即刻**被阻擋，無法越過其後方**。
* 唯有從其他未被敵軍阻擋的分支路徑繞行（生子時），或利用規則三純直線吃子剛好抵達該敵棋並將其吃掉，後續回合才能通過該處。

### 🏆 結束與勝負判定
1. **無步可走直接 PASS 並由對手直接指定點數**：若擲出骰子點數後，在當前盤面與點數下**完全沒有任何合法的走法（生子或吃子皆受阻），不僅直接 PASS 跳過本回合給對手，而且對手不用擲骰子，可直接指定骰子點數（1~6 步或自訂點數）**，接著進行生子或吃子！
2. **終局判定（雙方不可能互相吃子時直接填子比數量 + 割目結算）**：若雙方在行棋方向與盤面幾何的**可能性上已不可能互相吃子**（雙方勢力已完全交錯通過或形成不可突破之壁壘），遊戲直接宣告進入終局！此時**直接依照規則一與規則二將剩餘所有空格填滿雙方的勢力範圍**，最後**將白棋子數加上割目（預設 +3.5 目）後與黑棋子數比較多寡決定勝負**！
   > 💡 **為什麼不可互吃時可以直接填子？（博弈原理說明）**：  
   > 因為規則設有「無合法步數時，對手享有免擲骰直接指定點數」的特權。當雙方在盤面上已完全不可能互相吃子時，若某方擲出卡住的點數無步可走，對手即可自由指定點數生子推進。因此，雙方勢力範圍內的空格在博弈演變下必然會被各自依規則一、二合法填滿。既然一直擲骰子填子的**最終收斂結果完全相同**，此時直接自動填滿空格，可免去漫長繁瑣的重複擲骰（當然，一直手動擲骰填子也是可以的，只是最後的結果也是一樣）。
3. **全滅判負**：若某一方的棋子被全數吃光，因無子可動亦直接落敗。

### 🛠️ 自由擺盤、指定骰子與歷史回覆功能
* **✏️ 自由擺盤**：切換至擺盤模式即可在棋盤上任意放置黑棋、白棋或清空格子，自由排定局勢後，可指定先手方並**「接著下下去」**！
* **🎯 指定點數**：在對弈面板中，除了隨機擲骰外，亦可直接點選指定 1～6 點，享有特權時免擲骰直接指定！
* **⏪ 對局歷程回覆**：點擊右側「對局歷程」中的任意一手（或 **#0 開局初始局面**），棋盤將直接回覆至該步的局面（包含棋子配置、行動輪次、當手行棋路徑、割目設置），並可自由自該局面接續行棋或覆盤研究！

### 🤖 CPU 演算法階梯配置與五階對弈
在每回合擲 1 顆骰子下，CPU 演算法即時精算該步棋的盤面全局價值；若享有對手 PASS 帶來的指定點數特權，CPU 更將全面比對 1～6 步挑選最高價值點數下子：
1. **【Lv 1：v1 經典地力（純貪心 / 入門）】**：
   * **己方地力**：假設該格為己方棋子，依規則所能覆蓋抵達的空格總數。
   * **對手地力**：假設該格為敵方棋子，依規則所能覆蓋抵達的空格總數。
   * **生子價值** = $\text{目標己方地力} + \text{目標對手地力}$
   * **吃子價值** = $\text{目標己方地力} + 2 \times \text{目標對手地力} - \text{出發地己方地力}$
2. **【Lv 2：v2 戰術大局（防守 / 壓制 / 邊際 / 防 PASS）】**：
   * **落子直線防守（杜絕送子）**：即時檢驗目標格是否落在敵方直線吃子射程內，避免下回合被直接吃掉（施加 $-22 \sim -45$ 懲罰）；原位遭瞄準而藉吃子逃脫則獲 $+16$ 脫險獎勵。
   * **邊際全隊新拓地力（杜絕扎堆）**：以全隊覆蓋聯集計算「真正為全隊新開拓的未覆蓋面積」，激勵棋子朝未開拓的中央與外圍進攻。
   * **敵方動脈壓制（戰略卡位）**：計算落子切斷對手射線後，敵軍全軍地盤縮小了多少（$\Delta_{\text{suppress}} \times 1.8$），主動扼守交通要道。
   * **出步靈活性保障（防被罰 PASS）**：檢查落子後下一回合面對 $1 \sim 6$ 點的出步存活率，避免狹窄卡死自己送給對手自選點數特權。
3. **【Lv 3：v3 預期搜尋（Expectiminimax 深度 2 機率推演）】**：
   * 展開我方所有候選走步，並全面遍歷對手在下回合擲出 $1 \sim 6$ 點的完整期望值（Expectation），尋求極小化對手最大獲益（Minimax）的最佳路徑。
4. **【Lv 4：v4 深度反擊（3 層預期推演 / 反撲防陷阱）】**：
   * 推進至 3 層博弈樹深搜（我方走步 ➔ 敵方 6 骰 Min ➔ 我方 6 骰反擊期望 Max），並對兌子反撲陷阱精準預警，具備極強的防禦與抓破綻反殺實力。
5. **【Lv 5：v5 戰略宗師（兩階段深搜 / 預設推薦）】**：
   * 先以 v4 篩選全部候選走法，再把前 5 名以更深的搜尋（深度 4）重新驗證，多看一層對手的反擊，作為最終排序。**AI 教練的提示也使用該方所選的演算法**（預設 v5）。
6. **對弈與觀戰控制**：
   * 可自由為黑棋與白棋指派不同角色與演算法（支援人類 vs 人類、人類 vs CPU、CPU vs CPU 任意配置）。
   * CPU vs CPU 時可**暫停／繼續**，並可隨時接手：暫停時直接在棋盤上下出合法一步，輪到的那一方就會轉為人類。人機對戰時 CPU 輪到就直接下，不會暫停。
   * 可調整**行棋速度**，歷程可單步回放。

### 🧪 演算法評測
`tests/ai-tournament.js` 讓 v1 ~ v5 兩兩對戰（含自己對自己），輸出勝率、信賴區間、黑白分色、先手與割目是否平衡等統計：
```bash
node tests/ai-tournament.js --games 10 --seed 1 --out result.jsonl
```
`--out` 會逐局存檔，中斷後可加 `--resume` 續跑；`--algos`、`--komi`、`--workers` 可調參賽者、割目與平行數。v4、v5 運算較慢，局數多時請預留時間。

```bash

```
