# 三個棋類遊戲

線上直接玩：[https://3epiossi.github.io/](https://3epiossi.github.io/)

本地執行：在專案資料夾執行 `npm start`，用瀏覽器開啟 `http://localhost:8000`。程式以 ES 模組載入，直接雙擊 `index.html` 多半會被瀏覽器擋下。

介面支援中文、English、日本語。每一頁標題都是同一個遊戲切換器，可以切換遊戲，或進入該遊戲的規則學院。

## 五連黑白棋

目標：同一組的棋連成五顆就贏。

1. **64 顆棋，分 4 組**：棋上的字就是組別，每組 16 顆，雙方共用。輪到你時，自己選一組下。
2. **夾住才能下**：和黑白棋一樣，要夾住對手的棋，被夾住的全部翻成你的顏色。沒位置就 PASS。
3. **同組五連，立刻獲勝**：橫、直、斜都算。要連續 5 顆是你的顏色、而且同一組，翻面造成的也算。
4. **沒人連成五就數棋子**：整局沒有五連，比盤上棋子數，多的人贏（雙方合計 64）。

## 傑利蠑螈

目標：用牆把地圖切成選區，選舉人票最多的政黨獲勝。

1. **每格是社區，每點是選民**：格子裡的點是選民（1 點 = 1 票），底色是這一帶支持的政黨，越深代表領先越多。
2. **放牆，切出選區**：玩家輪流放 I4、S4、T4 牆塊。外框和海岸線本身就是牆，新牆不能沿著它放，也不能重疊。
3. **贏者全拿**：每個選區得票最多的政黨，拿走該區全部選舉人票。最後票數最多的政黨勝選。
4. **集中與打散**：把對手的票倉圍進少數選區，或把他的支持者切進你小贏的選區，就算全國總票數落後也能贏。

補充：選區小於最小選區（預設 2 格）時，選舉人票平分給所有政黨；區內平手也平分。

## 誰會贏？

目標：骰子決定步數，終局時勢力範圍最大的一方獲勝。

1. **每回合擲 1 顆骰子**：點數 D 就是這一步要走滿的步數。黑棋朝左、上進攻，白棋朝右、下進攻。
2. **生子**：選一顆己方棋，走滿 D 步到空格，原本的棋保留，目標格生出一顆新棋。途中可以穿過友軍。
3. **吃子**：像象棋的車，只能直線走滿 D 步，剛好停在敵棋上就吃掉它，原本的格子會變空。
4. **PASS 與終局**：沒步可走就 PASS，對手可以免骰指定 1 到 6 步。雙方不可能再互吃時，自動結算勢力範圍。
